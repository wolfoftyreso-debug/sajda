# Sajda Plus — USD 1,880 per month

The operator explicitly set the monthly price to **USD 1,880** on 2026-09-09.
This supersedes the prior USD 2,000 price, without currency conversion or a
change to the plan's features, limits, tax treatment or billing frequency.

`shared/plus-plan.ts` defines the shared contract: `188_000` cents, `usd`, one
month. Swedish display: `1 880 USD / månad`. English display: `USD 1,880 / month`.
The browser and server validate actual provider evidence against this same
contract. A stale USD 2,000 Price must not be accepted for a new purchase.

This code change does not activate Stripe, create a subscription, debit a
customer or alter a test-access grant. Before enabling checkout, the configured
Stripe Price must match USD 1,880 monthly and pass the existing provider and
release checks documented in `COMMERCE.md`.
